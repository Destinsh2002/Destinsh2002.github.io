Artifact Overview

The artifact I selected for this category is the SNHU Investments project that I completed during CS-410. This application allows users to manage client investment information and demonstrates searching, sorting, and data management using C++.

I chose this project because it demonstrates my understanding of algorithms and data structures while also giving me the opportunity to improve an older project. The enhancements focused on improving efficiency, reducing duplicated code, and making the application easier to maintain.

Enhancements

For my enhancement I redesigned the search functionality, improved how investment data is stored, removed duplicated code, and reorganized several functions to improve readability and maintainability. These changes made the program easier to expand while also improving overall code quality.
