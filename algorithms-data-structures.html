Artifact Overview

I selected my CS-410 Investment Company project for this category. The original program kept track of customer investment information but it used a lot of repeated code and seperate variables for each customer.

I picked this project because it gave me a good oppurtunity to improve the program using better data structures while also making the code easier to read and maintain.

Enhancements

The biggest change I made was replacing the seperate customer variables with a Customer struct and storing all of the customers inside a vector. I also added search functions that let users search by customer ID or customer name. I cleaned up repeated code, added helper functions, and improved the input validation. These changes made the program much easier to update and understand.
