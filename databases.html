Animal Shelter Dashboard

Artifact Overview

The artifact I selected for this category is my Animal Shelter Dashboard project that I completed during CS-340. The dashboard connects a MongoDB database to a web-based interface and allows users to search and view animal records.

I chose this project because it demonstrates database development and gave me the opportunity to improve an older project by adding new features and improving the overall code.

Enhancements

For my enhancement I added an advanced search feature, improved validation throughout the CRUD class, added sorting options, moved the database credentials into environment variables, and added MongoDB indexes to improve performance. I also updated the project so it would run correctly outside of the original SNHU Jupyter environment.

  • Database validation
