CS-340 Animal Shelter Dashboard

Artifact Overview

I selected my CS-340 Animal Shelter Dashboard for this category. The project connects a MongoDB database to a dashboard that lets users view and filter animal shelter records.

I picked this project because it gave me a good chance to improve my database skills while also making the dashboard easier to use. It also showed how a database can work with a user interface.

Enhancements

I added an advanced search feature that lets users search by breed, animal name, sex, rescue type, and age range. I also added sorting, better input validation, error handling, and MongoDB indexes for the fields that are searched the most.

I also moved the database login information into environment variables instead of leaving it hardcoded in the program. These changes made the project easier to use, easier to maintain, and a little more secure.
