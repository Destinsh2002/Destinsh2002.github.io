Professional Self-Assessment

Destin Shaffer

Introduction

Completing the Computer Science program at Southern New Hampshire University has helped me grow as both a programmer and a problem solver. Throughout the program I learned how to break larger problems into smaller pieces, debug issues more efficiently, and become more comfortable learning new programming languages and technologies.

This ePortfolio shows the projects I selected for my capstone and the enhancements I made to each one. Instead of creating new projects, I focused on improving existing ones by adding features, reorganizing code, and making the applications easier to use. I think these projects do a good job showing how much I have learned throughout the Computer Science program.

Technical Growth

One of the biggest things I gained from this program was more confidence in programming. When I first started learning new programming languages it felt overwhelming. Now I understand that once you learn the fundamentals it becomes much easier to pick up new languages and technologies.

I also improved my skills in software design, algorithms, data structures, databases, and security. Working on these capstone enhancements helped me look back at older projects and improve them instead of starting over. It showed me how important good organization, testing, validation, and maintainable code really are.
