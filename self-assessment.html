Professional Self-Assessment

Destin Shaffer

Introduction

Completing the Computer Science program at Southern New Hampshire University has helped me grow as both a programmer and a problem solver. Throughout the program I learned how to break larger problems into smaller pieces, debug issues more efficiently, and become more comfortable learning new programming languages and technologies.

This ePortfolio includes the three projects I selected for my capstone and the enhancements I made to each one. Instead of creating new projects, I focused on improving existing ones by adding new features, reorganizing the code, and making the applications easier to use. I think these projects do a good job showing how much I have learned throughout the Computer Science program.

Technical Growth

One of the biggest things I gained from this program was more confidence in programming. When I first started learning new programming languages it felt overwhelming. Now I understand that once I learn the fundamentals it becomes much easier to learn a new language or technology.

I also improved my skills in software design, algorithms, data structures, databases, and security. Working on these capstone enhancements helped me look back at older projects and improve them instead of starting over. It also showed me how important organization, testing, validation, and maintainable code really are.

Career Goals

I currently work at BAE Systems and my goal is to move into a software or test engineering position. The projects in this portfolio helped me build skills that I know I will use in that role. They also helped me get better at solving problems, debugging code, and learning new technologies.

Looking back at these projects made it easy to see how much I have improved since I started the Computer Science program. I still have a lot to learn but I feel much more confident than I did when I first started. I plan to keep building on these skills as I continue my career.
