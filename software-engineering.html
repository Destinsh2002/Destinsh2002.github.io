Software Design & Engineering

Weight Tracking Mobile Application

Artifact Overview

The artifact I selected for this category is my Weight Tracking Mobile Application that I created during CS-360. The application allows users to record their weight, view previous entries, and track their progress over time.

I chose this project because it demonstrates software design, user interface development, and object-oriented programming. It also gave me the opportunity to improve an older project by adding new features and cleaning up the code.

Enhancements

For my enhancement I improved the overall layout of the application, added a graph so users can better visualize their progress, improved input validation, and reorganized parts of the code to make it easier to maintain. These improvements made the application easier to use while also making the code more organized.
